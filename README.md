# Computer Vision

Notes and hands-on labs from my computer vision learning path, building toward 3D vision, sensor fusion, and autonomous vehicles perception.

## Structure

```
computer-vision/
│
├── notes/          # Concept explanations, math, and theory (my own words)
│   ├── 01-fundamentals/
│   ├── 02-image-processing/
│   ├── 03-features/
│   ├── 04-camera-geometry/
│   └── ...
│
└── labs/            # Hands-on implementations of each concept
    ├── 01-image-processing/
    ├── 02-edge-detection/
    ├── 03-corner-detection/
    └── ...
```

Each concept gets a matching pair: an explanation in `notes/` and an implementation in `labs/`, using the same numbering/naming so they're easy to cross-reference.

## Roadmap

Fundamentals → Image Processing → Feature Detection → Camera Geometry → Motion & Optical Flow → Stereo & Depth → 3D Vision

This repo is a living log. It grows as I go, not planned out in advance.

## Background

Background in AI/ML (TensorFlow, PyTorch, CUDA, OpenCV), now focused on building a solid computer vision foundation for perception-focused autonomous vehicles work. This repo documents that journey.
